Privacy policy

Applies to the application “rclone backup” of Hoffenbach. Last updated: 9 November 2026.

What the application does

rclone backup is an internal tool. It uploads the company's own backup files from the company server to the company's Google Drive and reads them back for restoring.

Google user data

  • The application accesses only the Google Drive of the company account that authorized it.
  • It uses this access only to create, update, read and move backup files.
  • It does not collect data from any other Google user.
  • It does not sell, share or transfer Google user data to third parties.
  • It does not use Google user data for advertising.

Storage

The access token is stored only on the company server. Backup files are stored only in the company's Google Drive.

Revoking access

The account owner can revoke access at any time at myaccount.google.com/permissions.
